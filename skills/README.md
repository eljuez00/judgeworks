# Skills

Reusable, tested capabilities that agents call instead of improvising. **Status: planned.**

The rule behind this folder, from the [Mac guide](../docs/guides/mac-local-llm.md): small models do best when they make the decisions and tested tools do the precise work.

## Candidates

- **HRIS query:** read employee and job data from the synthetic HRIS
- **Effective-dated diff:** compare two snapshots of job data and list each change
- **Policy search:** find the policy section that answers a question, with a citation
- **Pay compare:** compare a pay run with the previous one and explain the differences
- **HR platform lookup:** query the [HR Platform Library](https://eljuezproductions.com/hr-platforms) dataset
